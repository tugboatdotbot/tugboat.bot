Glossary: the words of this field, and what each project means by them

For: everyone. Last checked: November 10, 2026.

The short version

Section titled “The short version”
  • The field has settled words for most parts. An AI worker is an agent. The program that runs a model in a loop with tools is a harness. A connection to a chat app is a channel. A reusable package of instructions is a skill.
  • The projects do not all use them the same way. OpenClaw says “channel” where Hermes Agent says “platform”. “Heartbeat” means four different things in four projects.
  • Some things have no settled word yet. The always-on program in the middle is a “gateway” in two projects, a “server” in a third and a “host” in a fourth.
  • This site uses the standard word and defines it on first use. Where we use a word of our own, we say so. There are two: follow-through and virtual employee.

The standard words

Section titled “The standard words”
Word What it means You will also see
Agent One AI worker: a model that plans its own steps and uses tools in a loop to get a job done assistant; “AI employee” in small-business marketing
Subagent A second agent that an agent starts for one piece of work. It works in its own context and returns a summary sub-agent, worker
Multi-agent system Several agents working together. In plain speech, a team of agents agent team; “crew” in the CrewAI framework; “company” in Paperclip
Model The AI model itself, such as Claude or GPT LLM
Model provider The company or service that runs the model for you provider
Harness The program that runs a model in a loop with tools: it supplies file access, commands, permissions and memory. Claude Code and Codex are harnesses. Anthropic’s glossary puts it this way: Claude Code is the harness, and Claude is the model inside it agent harness, agent runtime, coding agent
Agent loop The cycle inside a harness: gather context, take an action, check the result, repeat agentic loop
Gateway In self-hosted assistants: the always-on program that holds the chat connections, the sessions and the scheduler. It has no AI in it; it passes work to the agents server, host, control plane, daemon
Channel A connection between an agent and a place people talk to it: Telegram, Slack, Microsoft Teams, a web page platform, chat connector; “surface” for any place an agent appears
Session One conversation and its state. The stored text is the transcript, or session history thread, conversation
Context window What the model can see at one moment. When it fills, the harness summarises older parts; that is compaction context
Memory What an agent keeps between sessions, usually notes it writes for itself in files long-term memory
Instructions The files that tell an agent its role and rules, such as AGENTS.md or CLAUDE.md. The model receives them as its system prompt system prompt; persona for the character part
Skill A reusable package of instructions an agent loads when it needs it: a folder with a SKILL.md file. An open format that most projects now share Agent Skill
Tool One action an agent can take: read a file, run a command, send a message action, function
MCP server A small program that gives an agent a set of tools over the Model Context Protocol, an open standard for connecting agents to services connector, for a ready-made one
Plugin Add-on code for the system itself, as opposed to a tool for the agent extension
Scheduled task Work that starts at set times. The part that starts it is the scheduler cron job, automation, routine
Heartbeat In the OpenClaw family: a regular “is there anything to do?” check. See “Words that trap” below
Trigger An event that starts work: a new message, a webhook, a file change hook, wakeup
Task A piece of work. One execution of it is a run. One exchange in a conversation is a turn issue, job, card
Approval A person saying yes before an agent acts. The general idea is human-in-the-loop confirmation, permission prompt
Permissions Which tools an agent may use, and with what arguments tool policy, rules
Sandbox A technical wall around where an agent’s commands run: a container, a virtual machine, or operating-system isolation container, environment
Allowlist The list of people or things that are let through. Everyone else is refused pairing, for adding a person to it
Prompt injection Hidden instructions in something an agent reads, such as an email or a web page, written to make it misbehave
Subscription and API key The two ways the AI is paid for: a monthly plan you sign in to, or a password-like code billed by the amount used plan; usage-based, pay-as-you-go
Workspace The folder an agent works in working directory
Follow-through Our own word. Every open task has one owner and a date, and the agent keeps asking until it is closed. The field has no noun for this; the nearest descriptions are “task tracking with follow-ups” and “human-in-the-loop”

Words that trap

Section titled “Words that trap”

These words are standard, and still mean different things in different places.

  • Heartbeat. In OpenClaw it was a periodic check driven by a HEARTBEAT.md file; since August 2026 it is an ordinary scheduled job there. In Hermes Agent it is one recurring prompt inside a single session. In Paperclip it is any short run of an agent, timed or not. In NanoClaw it is a file that shows an agent is alive.
  • Gateway. In OpenClaw and Hermes Agent it is the always-on program described above. Elsewhere it can mean a proxy that sits in front of model providers, or a proxy that sits in front of tools. Paperclip has a “tool gateway” of that second kind.
  • Adapter. In Paperclip, the bridge between its server and one harness. In Hermes Agent, the code for one chat app.
  • Provider. Almost everywhere, whoever serves the model. In NanoClaw, the agent program that runs inside the container.
  • Connector. At Anthropic, an MCP server added to your claude.ai account. In Paperclip, a chat connection.
  • Runtime and harness. Often used for the same thing. LangChain’s split is the tidiest: a framework is a library you build with, a runtime keeps long work running and resumable, a harness is the ready-made program with tools included.
  • Routine. Anthropic’s former name for a cloud scheduled task. Paperclip’s current name for a scheduled job.
  • Hub. A registry or marketplace, such as ClawHub for OpenClaw skills. Not the always-on program.
  • Crew. A specific object in the CrewAI framework. Used as a common noun, it makes developers think of CrewAI.
  • Agent group. In NanoClaw, one agent. Not a group of agents.

What the two kinds of product are called

Section titled “What the two kinds of product are called”

One person’s always-on assistant. The products call themselves a “personal AI assistant” or “personal AI agent”. Since February 2026 developers also say “claw”, after OpenClaw: Andrej Karpathy wrote that “Claws are now a new layer on top of LLM agents”, and Simon Willison called it a term of art for OpenClaw-like systems that run on personal hardware and talk over messaging apps (Willison, February 21, 2026). The word is real and current. It is also less than a year old.

An AI worker inside a company. Small-business products such as Lindy and Sintra say “AI employee”. In 2026 the large vendors chose “AI coworker”: OpenAI for Frontier, Microsoft for Copilot Cowork, Salesforce for Agentforce Coworker. This site says “AI employee” for the general idea. “Virtual employee” is our own phrase for one that joins a team under its own name; we found no other project using it.

Sources and dates

Section titled “Sources and dates”
  • Each project’s words were read from its own documentation and, for Paperclip, its source code, on November 10, 2026. The pages are listed at the end of the feature matrix.
  • The standard words were checked against the documentation of Anthropic, OpenAI, Google, Microsoft, LangChain, CrewAI and the Model Context Protocol on the same date.
  • Most pages were read through a tool that summarises. Quotes are as it returned them. Check the page before relying on exact wording.
  • Vocabulary in this field moves quickly. “Harness” settled only during 2026.
