What do Anthropic and OpenAI allow, by sign-in?

For: the builder, the decider in a team, and the owner who wants to know what is safe to sign in to. Last checked: November 9, 2026.

The short version

Section titled “The short version”
  • The rules follow the sign-in, not the program. What matters most is who signed in and with what: a monthly plan or an API key. Whether a program uses the command line or a code library makes no difference.
  • A monthly plan is for the person who pays for it, used through the AI company’s own apps. That includes running the company’s own agent harness (the program that runs the model in a loop with tools; Anthropic’s is Claude Code, OpenAI’s is Codex) yourself.
  • An API key is for programs. An API key is a password-like code that bills by the amount used, under business terms. Products are expected to run on one.
  • A product may not offer sign-in with your Claude plan unless Anthropic has approved it. OpenAI draws the same line with one official exception: “Sign in with ChatGPT”, which lets open-source and local personal apps use your ChatGPT plan.
  • One case is unclear: someone else’s tool starting the Claude Code you installed, on your plan. No Anthropic page says yes or no.

This is our reading of the companies’ public pages on the date above. It is not legal advice. These rules changed several times in 2026, so check the linked pages before you build on them.

Three words first

Section titled “Three words first”
  • Plan: a flat-price monthly subscription, such as Claude Pro or Max, or ChatGPT Plus or Pro.
  • API key: access for programs, paid by the amount used.
  • Harness: short for agent harness, the program that lets the AI use tools and work in steps. Anthropic’s is Claude Code. OpenAI’s is Codex. Each can be used in a window by a person, or started by another program for one short run at a time.

What happened in 2026

Section titled “What happened in 2026”
  • January: Anthropic’s servers began rejecting third-party tools that signed in with a Claude plan.
  • February: the terms limited plan sign-in to Claude Code and claude.ai.
  • April 4: Anthropic stopped covering third-party tools such as OpenClaw under Claude plans. One news report put the number of affected OpenClaw installs at about 135,000. That counts installs, not people. Those tools now need an API key, paid extra usage, or to start the user’s own installed Claude Code, which is the unclear case below.
  • June 15: Anthropic paused a change, announced earlier, to how Agent SDK use counts against plans, according to its help article.
  • October: Max, Ultra and Team plans began to include monthly API credits for programmatic use.

Sources for this list: InfoWorld, The Register, AlternativeTo, and Anthropic’s help article.

Signs that plan use by programs may narrow

Section titled “Signs that plan use by programs may narrow”
  • The paused June change, above.
  • Anthropic’s page on running Claude Code from scripts says a mode called --bare will become the default for short runs. Bare mode never reads the plan sign-in. It needs an API key. (Run Claude Code programmatically)
  • The monthly API credits point the same way: programs on API billing, people on plans.

The SDK changes nothing

Section titled “The SDK changes nothing”

The Agent SDK is a code library. Anthropic describes it as “a library that runs the Claude Code binary” (the binary is the program file), so it is the same harness as claude -p. Using the SDK is allowed. What is restricted is the sign-in: a third-party product may not offer claude.ai login or plan limits, “including agents built on the Claude Agent SDK”. On an API key, both routes are clean. On someone else’s plan, both raise the same question.

OpenAI (ChatGPT)

Section titled “OpenAI (ChatGPT)”
What you do Standing Where it says so
Run Codex yourself on your ChatGPT plan Allowed Codex authentication
Have your own script start Codex (codex exec), or use the Codex SDK (a library that controls the Codex program) Allowed. OpenAI adds: “API keys are still the recommended default for automation.” Codex authentication
Use an open-source or local personal app that offers Sign in with ChatGPT Officially offered. Plan usage “is available to all open-source partners and selected private clients” Sign in with ChatGPT quickstart
Use a paid or hosted app that offers Sign in with ChatGPT A waitlist, with a limited trial for selected commercial partners Same page
Let someone else’s tool drive the Codex you installed, on your plan Not addressed on OpenAI’s pages None found
Use any app on an API key Allowed. Billed by use None read. This is the ordinary API arrangement

“Sign in with ChatGPT” is the clearest yes either company gives for using a plan inside someone else’s open-source app. The New Stack reports that OpenAI opened it to Plus and Pro subscribers on September 29, 2026, with usage drawn from the plan’s allowance and weekly caps per app (The New Stack). Anthropic has no equivalent.

It has a cost for builders. It gives model calls, not a harness. Codex brings file tools, approvals and saved sessions. An app using Sign in with ChatGPT alone has to supply those tools and steps itself.

We have not checked which models and tools are eligible, what the limits are, or whether registering an app is reviewed.

The unclear case

Section titled “The unclear case”

A tool you install can start the Claude Code that you installed and signed in to yourself. Such a tool does not need to see your sign-in: Claude Code keeps it. Is that “your own use”, or “another company’s product on your plan”?

  • For it being fine: the tool’s code need not touch the sign-in, and OpenClaw’s documentation says its code never reads or forwards it. Anthropic’s help article says claude -p “and third-party app usage still draw from your subscription limits”, which treats such use as something that happens.
  • Against: no Anthropic page says a third-party tool may do this, and the signs above point toward API keys for programs.
  • Who ships it: OpenClaw and Paperclip both start the user’s own Claude Code. OpenClaw’s documentation calls this “sanctioned for this integration”. It cites no Anthropic source for that, and the same documentation recommends an API key for shared or always-on use. (OpenClaw: Anthropic provider, Paperclip: Claude Code adapter)

Hermes Agent takes a different route: its sign-in with a Claude plan “only works if you’re on a Claude Max plan and have purchased extra usage credits”, which makes it pay-per-use in practice (Hermes providers).

If you rely on the unclear case, treat it as personal use that may stop working, and keep an API key as the fallback.

What this means for you

Section titled “What this means for you”

If you own a practice or a small business

  • Using Claude or ChatGPT in the AI company’s own apps, on a plan you pay for yourself, is allowed.
  • Be careful with any product that asks you to sign in with your Claude plan inside their app. Unless Anthropic approved that product, this is the use the rules block.
  • A hosted product bills you its own way. A self-hosted one runs on an API key billed by use, on Sign in with ChatGPT where it offers that, or by starting your own Claude Code on your plan, which is the unclear case above.

If you build these systems

  • For a product other people use, build on API keys. That is the supported route at both companies.
  • If you want people to use a Claude plan they already pay for, keep the official Claude Code in charge. Each person installs it and signs in themselves. Your part is settings and tools. For chat, point people to Anthropic’s own channels and apps, such as the official Telegram channel or the Claude app. A chat window of your own needs the development flag, which is meant for the person building the channel. Your product also must not look like Claude Code or an Anthropic product.
  • For ChatGPT plans in an open-source app, Sign in with ChatGPT is the official route.
  • If you ship the unclear case, say so plainly and leave it off by default.

If you decide for a team

  • An agent (one AI worker) that many colleagues use should run on the business’s own account, such as an API account, not on one person’s plan. Anthropic’s consumer terms forbid making a personal account available to other people (consumer terms). Check the current wording.
  • On Team and Enterprise plans, an admin can approve channel plugins (the add-ons that link a chat app to Claude Code) for the whole organization, so the development flag is not needed there. (Channels reference)

What we make

Today Tugboat runs only for its builder. Its gateway starts the Claude Code its builder installed and signed in to, one run per message, on that person’s own plan. For anyone else, that is the unclear case above, and we would say so to anyone who installs it. Tugboat never signs in for anyone. It can also use an API key, which has not been tried with a real key yet. A route for people on ChatGPT plans is planned and not built. Where Tugboat stands.
